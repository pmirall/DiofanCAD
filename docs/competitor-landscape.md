# DiofanCAD — Competitor Landscape

## Purpose

Understand competing workflows without copying implementation details blindly.

## Required comparison set

V7 requires tracking at least:

- FreeCAD upstream;
- Fusion 360;
- FuCad;
- UniCAD;
- relevant RealThunder / Assembly3 work;
- historical Ondsel work where technically relevant.

## Comparison method

For every capability:

```text
Observed behavior
 ↓
User problem
 ↓
Underlying mechanism
 ↓
Our alternative
 ↓
Benchmark
 ↓
Decision
```
