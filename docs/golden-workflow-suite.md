# Golden Workflow Suite

## Propósito

Conjunto estable de workflows representativos para medir DiofanCAD contra una baseline comparable y contra competidores cuando sea reproducible.

## Workflows

### Mechanical
1. Bracket
2. Parametric enclosure
3. Gearbox
4. Mounting assembly
5. Motion assembly

### Product
6. Complex housing
7. Surface-heavy consumer object

### Manufacturing
8. 3-axis milling part
9. Multiaxis candidate

### CAE
10. Structural simulation

### Electronics
11. PCB enclosure with connectors and keepouts

### Documentation
12. Released drawing + BOM + revision

### Integration
13. End-to-end product release

## Reglas

Cada workflow debe tener starting state, target state, constraints, timing protocol, expected outputs, failure taxonomy y change challenge.

No se deben adaptar los workflows para favorecer DiofanCAD o el competidor después de observar resultados.
